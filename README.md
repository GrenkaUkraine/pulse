<h1 align="center">Pulse IDE</h1>

<p align="center"><strong>Visual programming for Arduino</strong></p>

<p align="center">
  <img src="https://img.shields.io/badge/WIP-WORK%20IN%20PROGRESS-F5A623?style=for-the-badge" alt="WIP — Work in progress" width="360">
</p>

---

Pulse IDE is a node-based editor for building Arduino programs. Connect nodes on a canvas to define control flow, work
with values, and interact with hardware. ESP32 support is planned for the future.

> [!IMPORTANT]
> **Pulse IDE is in early development.** The first release has no set date yet. Stay tuned!
